# 真实家装数据采集清单

目标：围绕一个真实户型，把设计、深化、施工、竣工数据收集完整，最后转成可还原的 `spatial-meta`。

## 最小必拿 10 件

1. 原始户型图或建筑 CAD
2. 平面布置图
3. 天花吊顶图
4. 水电点位图
5. 中央空调 / 新风方案图
6. 地暖盘管图
7. 给排水图
8. 设备型号清单
9. 隐蔽工程照片
10. 竣工图或现场变更记录

## 按角色要资料

| 找谁 | 要什么 |
|---|---|
| 业主 / 物业 | 原始户型图、开发商交付图、承重限制、物业施工要求 |
| 室内设计师 | 平面、吊顶、立面、节点、材料、柜体、水电点位 |
| 暖通公司 | 空调、新风、冷媒管、冷凝水、风口、外机、设备表 |
| 地暖公司 | 分集水器、盘管回路、管间距、供回水方向、压力测试 |
| 水电师傅 | 冷热水、排水、强弱电、配电箱、开关插座、控制线 |
| 设备厂家 | 型号、尺寸、接口、安装说明、CAD 图块、BIM 族库 |
| 监理 / 工长 | 隐蔽工程照片、变更单、验收记录、竣工图 |

## 按阶段收集

### S0 现场原始状态

- 毛坯 / 旧房现场照片
- 实测尺寸
- 原始户型图
- 承重墙、梁柱、管井、烟道、地漏、排污口位置

### S1 设计阶段

- 平面布置图
- 墙体拆改图
- 天花吊顶图
- 地面铺装图
- 灯具定位图
- 开关插座图
- 立面图
- 节点大样图
- 材料表

### S2 机电深化阶段

- 中央空调内机点位
- 外机位置
- 风管走向
- 送风口 / 回风口 / 新风口 / 排风口位置
- 冷媒管路径
- 冷凝水管路径和坡度
- 新风主机和管线
- 地暖分集水器和盘管
- 冷水 / 热水 / 排水路径
- 电路回路和控制点位
- 管径、风量、标高、检修口

### S3 隐蔽施工阶段

必须拍照：

- 空调内机安装前后
- 风管封板前
- 冷媒管 / 冷凝水管封闭前
- 新风管封板前
- 地暖盘管覆盖前
- 分集水器接管
- 厨卫冷热水和排水
- 配电箱和线管
- 墙面开槽
- 吊顶封板前全景

### S4 封板和安装阶段

- 吊顶封板后
- 检修口位置
- 风口安装
- 灯具安装
- 开关面板安装
- 洁具安装
- 柜体遮挡前照片

### S5 竣工交付阶段

- 竣工图
- 现场变更单
- 设备验收单
- 压力测试记录
- 空调 / 新风调试记录
- 地暖调试记录
- 最终全屋照片和视频

## 每个文件要记录什么

每个文件都要登记：

- 文件名
- 类别
- 阶段
- 专业
- 来源人
- 日期
- 版本
- 格式
- 能证明什么
- 是否已用于建模

每张照片都要登记：

- 拍摄阶段
- 房间
- 系统
- 拍摄方向
- 能证明什么

## 数据合格标准

能做展示级还原：

- 有户型图
- 有主要机电方案图
- 有设备表
- 有隐蔽照片

能做空间 meta：

- 有 CAD / IFC / 可解析图纸
- 有设备型号和尺寸
- 有管线路径和标高
- 有系统连接关系

接近施工级：

- 有施工图
- 有深化图
- 有竣工图
- 有现场变更
- 有隐蔽工程照片
- 有验收记录
- 有关键尺寸复测

## 给合作方的话术

可以直接发：

> 我们想做一个真实家装项目的全屋机电三维可视化和隐蔽工程归档。你们提供 CAD/PDF 图纸、设备清单、产品资料和施工阶段照片，我们会整理成一套可展示、可追溯的三维交付样板。所有资料都会记录来源、版本和用途，不会覆盖原始施工文件。
